**Energy Consumption and Prediction**

**Objective**
Develop a machine learning and time-series forecasting model to analyze historical energy consumption patterns and predict future energy usage.

**Tools**
Python
NumPy
Pandas
Scikit-learn
Jupyter Notebook
ARIMA
Prophet

**Methods**
Cleaned and preprocessed energy consumption data.
Performed exploratory data analysis to identify consumption patterns and trends.
Applied time-series forecasting techniques using ARIMA and Prophet.
Evaluated and compared model predictions to identify suitable forecasting performance.

**Outcome**
Successfully developed an energy consumption prediction model that can forecast future usage and provide insights into consumption trends. The project strengthened my practical skills in Python, data analysis, machine learning, and time-series forecasting.
